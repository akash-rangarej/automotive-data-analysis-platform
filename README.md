# 🧠 Data Analysis Platform

A **comprehensive web-based data analysis and visualization tool** that helps users process, analyze, and visualize datasets through an intuitive interface.

---

## 🚀 Features

### 📂 Data Upload & Handling
- Supports **CSV** and **Excel** file formats (`.csv`, `.xlsx`, `.xls`)
- Automatic **data type detection**
- **Preview functionality** (first 10 rows)
- Secure **file handling** and validation

---

### 📊 Data Analysis
- **Missing Values Analysis**: Detect and analyze null values  
- **Outlier Detection**: Statistical analysis using the **IQR method**  
- **Value Counts**: Frequency analysis for categorical columns  
- **Column Type Information**: Automatic detection of numerical and categorical data  

---

### 🎨 Visualization Capabilities
- **Line Plots** – For trend analysis  
- **Bar Plots** – For comparative analysis  
- **Scatter Plots** – For correlation analysis  
- **Pie Charts** – For proportion analysis  
- **Heatmaps** – For correlation matrix visualization  
- **Box Plots** – For distribution and outlier analysis  
- **Histograms** – For distribution analysis  
- **Pair Plots** – For multi-variable relationship analysis  

---

### ⚙️ Data Preprocessing Pipeline
- **Missing Value Handling** – Intelligent imputation for numerical and categorical data  
- **Feature Scaling Options**:
  - Standard Scaling  
  - MinMax Scaling  
  - Robust Scaling  
- **Categorical Encoding**:
  - One-Hot Encoding  
  - Ordinal Encoding  
  - Label Encoding  
- **Outlier Handling** – IQR-based outlier removal  

---

### 🤖 Model-Specific Processing
Specialized preprocessing pipelines for:
- Linear Models  
- Tree-based Models  
- Distance-based Models  
- Clustering Models  
- Neural Networks  
- Naive Bayes  

---

## 🧰 Tech Stack

### 🔙 Backend
- **Flask** – Python web framework  
- **Pandas** – Data manipulation  
- **NumPy** – Numerical operations  
- **Scikit-learn** – Data preprocessing  
- **Matplotlib / Seaborn** – Data visualization  
- **OpenPyXL / XLRD** – Excel file handling  
- **Flask-CORS** – Cross-origin resource sharing  

### 🔝 Frontend
- **React.js** – UI development  
- **Modern CSS** – Responsive design  

---

## ⚙️ Installation & Setup

```
git clone https://github.com/yourusername/data-analysis-platform.git
cd data-analysis-platform

pip install flask pandas numpy scikit-learn matplotlib seaborn openpyxl xlrd flask-cors

python app.py

cd frontend
npm install
npm start

```
